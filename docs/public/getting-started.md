# 導入と使い方

## インストール

対象はWindows x64です。ARM64のネイティブ実行には対応していません。
最低メモリ容量はまだ保証していません。モデル読み込み時には常駐時より多くのメモリを使用します。

1. 公開リポジトリのReleasesからWindows用ZIPとSHA256SUMS.txtを取得します（現在は公開準備中）。
2. PowerShellの `Get-FileHash .\gourdy-0.7.0-windows-x64.zip -Algorithm SHA256` でハッシュを照合します。
3. ZIPを任意のフォルダーに展開します。exeだけを取り出さず、付属のresourcesなどを一緒に置きます。
4. `Gourdy.exe` を起動します。開発版はコード署名されていません。提供元を確認できないファイルは実行しないでください。
5. Windowsのマイクアクセスを許可し、歯車から「操作」で使用するマイクを選びます。

## 話しながら入力する

入力先の編集欄をクリックしてから **右Ctrlを押して離す** で録音を始めます。同じショートカットで停止します。
マイクボタンでも開始・停止できます。ショートカットは設定から変更できます。
認識途中の文字を送り、変更された末尾をBackspaceで修正します。
入力中に別の場所をクリックしたり、手で文字を編集したりすると、誤操作を避けるため自動入力が止まることがあります。
自動入力だけが止まった場合も録音・認識は続き、吹き出しに続きを表示します。録音停止後はミニ画面からコピー、または入力欄を選んで「続きを入力」を押せます。入力済み範囲を確認できない場合は全文コピーで確認してください。
この補助は操作設定で無効化できます。

「アプリで確認してから貼り付け」を選ぶと、録音後の結果を履歴で確認できます。
貼り付け操作の後、入力したい位置をクリックします。

## 丸型の録音画面

中央の大きなマイクで開始・停止、右下の歯車で設定を開きます。上のバーはマイク音量、左下は状態と設定中のショートカットです。
本体にポインターを乗せると右上に×が現れ、トレイに隠せます。マイク周囲の白い縁をドラッグすると移動できます。右下にホバー時に現れるつまみをドラッグすると、縦横比を保ってサイズを変更できます。位置とサイズは次回起動時にも復元します。

## 設定

- **操作**：入力方式、ショートカット、マイク、ノイズ抑制、アクセントカラー。
- **辞書**：表記と読みを登録。編集は自動保存。個別削除、辞書ファイルの取り込み・書き出し。
- **履歴**：コピー、貼り付け、個別削除、録音の再認識。
- **ファイル読込**：音声・動画の読み込み、プレビュー、文字起こし・再開。
- **その他設定**：アクセントカラー、履歴の保存件数・文字数、起動時実行、タスクバー、MCP接続、データ削除。
- **アプリ情報**：バージョン、使用モデル、保存先。

## 会議の音声・動画

履歴の「音声・動画を選ぶ」からファイルを開きます。最長12時間です。
プレビューで音声を確認し、処理を開始します。長い音声は区間ごとに途中結果を保存します。
失敗した区間は再試行でき、中断後は未完了の区間から再開できます。
再開するまでは元ファイルを移動・変更しないでください。話者分離はありません。

## 保存と削除

設定・辞書・履歴は `%APPDATA%\local-dictation-streaming\app-data.json` に保存します。
同じフォルダーの `recordings` に保存録音、`meetings` に会議処理の途中結果を保存します。
履歴は初期値10件、1件あたり最大12,000文字。保存件数・文字数はその他設定で変更できます。
録音保存は初期状態で有効です（最大10件・7日間、1録音の保存は最大5分）。
会議の途中結果は通常の履歴とは別管理です。不要な会議・録音は各一覧から削除してください。
ファイルは暗号化されていません。共有PCではWindowsアカウントのアクセス管理にも注意してください。

## 更新・終了

トレイメニューから終了してから、新しいZIPを別フォルダーへ展開して起動します。
実行中のフォルダーへの上書きは避けてください。設定と履歴はアプリフォルダーとは別に保存されます。
削除する場合はアプリを終了し、展開フォルダーを削除します。保存データも消す場合は上記AppDataフォルダーを別途削除します。

録音ショートカットは設定の「操作」で変更できます。左右Ctrl・Altの単独押し、Alt＋カンマなどの組み合わせに対応します。単独キーは離した時に動作し、他のキーやマウス操作と併用した場合は開始しません。既存のショートカット設定は更新後も保持します。設定ウィンドウにフォーカスがある間は録音ショートカットを抑止します。


## 設定画面

「操作」「辞書」「履歴」「ファイル読込」「その他設定」「アプリ情報」に分かれています。
辞書内では「用語辞書」と「表記の置換」を左右のタブで切り替えます。
音声・動画は「ファイル読込」、アクセントカラーは「その他設定」から設定します。
録音ウィンドウは幅168 DIPが初期値で、140〜420 DIPに変更できます。保存済みのサイズは保持します。

「操作」のノイズ閾値は、認識に送るマイク音声の最低音量です。左端の−80 dBはオフ。閾値を上げると小さな音を無音として送ります。語尾を切りにくくするため、閾値を下回った直後の約200msは残します。ファイル読込には適用しません。

## ローカルMCP接続

初期状態で `http://127.0.0.1:55888/mcp` のStreamable HTTP接続が有効です。Gourdyの起動中だけ接続できます。stdio方式は提供しません。
「その他設定」で無効化・ポート変更ができます。「接続設定をコピー」で認証トークン付きの設定例を取得し、MCPクライアントに登録してください。設定例の形式はクライアントによって異なりますが、URLとAuthorizationヘッダーは共通です。コピーした認証トークンは公開しないでください。

利用できるツール:

- `prepare_file`：ローカル音声・動画の絶対パスを検査してジョブIDを返します。
- `start_transcription`：IDを指定して開始・再開します。処理完了を待たずに応答します。
- `get_transcription`：進捗、区間のエラー、途中結果・全文を取得します。
- `list_transcriptions`：保存したジョブを一覧表示します。
- `cancel_transcription`：指定した実行中ジョブを中断します。保存済み区間は残ります。

一度に処理するジョブは1件です。録音中などは開始できず、理由を返します。MCP経由の結果も「ファイル読込」から確認できます。ローカル接続でも認証が必要で、外部からの接続や不正なOrigin/Hostは受け付けません。ポート使用中などで起動できない場合は設定画面に原因を表示し、別のポートへ黙って切り替えることはありません。

## 吹き出しと録音画面

通常時は録音画面の左下に文字を表示しません。マイクにマウスを乗せると、操作と設定中のショートカットを看板で表示します。エラーや入力停止などのお知らせがあると、左下に本体とつながる「i」ボタンが現れます。クリックすると、文字起こし結果とは別のお知らせ用吹き出しを開きます。×で吹き出しだけ閉じ、もう一度「i」で開けます。長い本文は縦スクロールします。お知らせの白背景は初期オンで、「その他設定」の「お知らせの背景を表示」で無効化できます。結合した円の本体にはシャドウを付けます。マイクと歯車の丸背景、音量バーは待機中からアクセントカラーを使い、録音中のマイクとバーは濃い色になります。

入力欄が見つからない場合もマイク録音を開始し、吹き出しへ文字起こしします。入力監視そのものの故障などはこの切替の対象ではなく、エラーを表示します。
入力途中にフォーカスが外れた場合も、未入力の続きが吹き出しに表示されます。停止後も残り、吹き出し専用の×か、入力欄にフォーカスした次の録音開始で閉じます。
吹き出し上部のコピー・入力ボタンは録音と補正の終了後に使えます。入力する場合は、入力先にカーソルを置いてから押してください。

改行はそのまま表示し、長文は本文だけ縦スクロールします。上部の操作ボタンは固定です。末尾を見ている間は自動追従し、過去の行を見返している間は位置を維持します。
