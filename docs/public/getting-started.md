# 導入と使い方

## インストール

対象はWindows x64です。Microsoft Visual C++ v14の最新x64ランタイムが必要です。未導入の場合は[Microsoft公式の案内](https://learn.microsoft.com/cpp/windows/latest-supported-vc-redist)からx64版をインストールしてください。ARM64のネイティブ実行には対応していません。
最低メモリ容量はまだ保証していません。モデル読み込み時には常駐時より多くのメモリを使用します。

### インストーラー版

ZIP版とインストーラー版を同じリリースページで配布しています。

1. Releasesから `gourdy-0.7.6-windows-x64-setup.exe` と `SHA256SUMS.txt` を取得します。
2. PowerShellの `Get-FileHash .\gourdy-0.7.6-windows-x64-setup.exe -Algorithm SHA256` でハッシュを照合します。
3. 起動中のGourdyをトレイから終了し、インストーラーを実行します。インストール先はユーザーのLocalAppData配下が初期値で、変更できます。
4. スタートメニューの「Gourdy」から起動します。0.7.6では実行環境のみ同梱し、モデルは別途取得します。Visual C++ランタイムは上記の前提条件です。
5. Windowsのマイクアクセスを許可し、歯車の「操作」でマイクを選びます。

コード署名はありません。提供元とハッシュを確認してください。自動更新には対応していません。次版のインストーラーで同じ場所へ更新します。
設定・辞書・履歴・追加取得モデルはAppDataに保存し、更新やアンインストール後も保持します。APIキーは更新時に保持し、アンインストール時に削除します。ZIP版はアンインストーラーがないため、削除前に設定の「AI接続」でキーを削除してください。
削除はWindowsの「インストールされているアプリ」から行います。保存データも削除する場合は、後述の保存先を別途削除してください。

### ZIP版

インストールせず使う場合は `gourdy-0.7.6-windows-x64.zip` を取得し、SHA256を照合して全体を展開します。
exeだけ取り出さず、付属のresourcesなどを一緒に置き、`Gourdy.exe` を起動してください。
ZIP版も設定はAppData保存です。インストーラー版と同じ設定・履歴を使用します。


## 初回の接続設定（0.7.6）

未設定時はお知らせの「AI接続を設定」から設定画面へ進みます。マイク操作や起動だけでは、モデルの取得・読み込み・録音を始めません。
「AI接続」でOpenAIまたはGeminiのAPIキーを登録して接続先を選ぶか、「ローカルモデルをダウンロードする」を押して取得後にローカルを選びます。
ローカル用には音声認識・標準補正・日本語解析のモデルを取得します。ローカル選択時は、マイク・ファイル・MCP・録音の再認識に同じローカルモデルを使います。BYOK選択時はこれらをAPIで処理します。
ダウンロードに失敗したら設定に原因を表示し、再試行時は検証済みのファイルを再利用します。
登録済みキーの「削除」は確認後にこのPCの保存キーを削除します。使用中の接続先なら未設定へ戻します。API提供元のキー自体の失効は提供元の管理画面で行ってください。

## 話しながら入力する

入力先の編集欄をクリックしてから **右Ctrlを押して離す** で録音を始めます。同じショートカットで停止します。
マイクボタンでも開始・停止できます。ショートカットは設定から変更できます。
認識途中の文字を送り、変更された末尾をBackspaceで修正します。
入力中に別の場所をクリックしたり、手で文字を編集したりすると、誤操作を避けるため自動入力が止まることがあります。
自動入力だけが止まった場合も録音・認識は続き、吹き出しに続きを表示します。録音停止後は吹き出し上部のコピー、または入力欄を選んで「入力」を押せます。コピー成功は吹き出し左上に表示します。コピーできない間はアイコンにホバーすると、録音・AI補正などの理由が表示されます。入力済み範囲を確認できない場合は全文コピーで確認してください。
この補助は操作設定で無効化できます。

「アプリで確認してから貼り付け」を選ぶと、録音後の結果を履歴で確認できます。
貼り付け操作の後、入力したい位置をクリックします。

## 丸型の録音画面

中央の大きなマイクで開始・停止、右下の歯車で設定を開きます。上のバーはマイク音量です。マイクにホバーすると設定中のショートカットが表示されます。必要時だけ左下に情報アイコンが現れ、クリックするとお知らせを開きます。お知らせを×で閉じると情報アイコンも消えます。
本体にポインターを乗せると右上に×が現れます。初期設定ではトレイに隠れ、その他設定で完全終了へ変更できます。トレイに隠した状態でも録音ショートカットで本体を表示します。マイク周囲の白い縁をドラッグすると移動できます。右下にホバー時に現れるつまみをドラッグすると、縦横比を保ってサイズを変更できます。位置とサイズは次回起動時にも復元します。

## 設定

- **操作**：入力方式、ショートカット、マイク、ノイズ抑制。
- **辞書**：表記と読みを登録。編集は自動保存。個別削除、辞書ファイルの取り込み・書き出し。
- **履歴**：コピー、貼り付け、個別削除、録音の再認識。
- **ファイル読込**：音声・動画の読み込み、プレビュー、文字起こし・再開。
- **MCP接続（開発中）**：ファイル文字起こし専用の接続と、接続先アプリへの設定追記。
- **その他設定**：アクセントカラー、履歴の保存件数・文字数、起動時実行、タスクバー、閉じる動作、データ削除。
- **AI接続**：ローカルモデル取得、BYOK接続先とAPIキーの登録・削除。
- **アプリ情報**：バージョン、使用モデル、保存先。

## 会議の音声・動画

ファイル読込の「音声・動画を選ぶ」からファイルを開きます。最長12時間です。
各区間の「この区間を再生」と標準プレーヤーで音声を確認し、処理を開始します。プレビューは区間単位で、全体の連続再生ではありません。長い音声は区間ごとに途中結果を保存します。
失敗した区間は再試行でき、中断後は未完了の区間から再開できます。
再開するまでは元ファイルを移動・変更しないでください。話者分離はありません。

## 保存と削除

設定・辞書・履歴は `%APPDATA%\local-dictation-streaming\app-data.json` に保存します。
同じフォルダーの `recordings` に保存録音、`meetings` に会議処理の途中結果を保存します。
履歴は初期値10件、1件あたり最大12,000文字。保存件数・文字数はその他設定で変更できます。
録音保存は初期状態で有効です（最大10件・7日間、1録音の保存は最大5分）。
会議の途中結果は通常の履歴とは別管理です。不要な会議・録音は各一覧から削除してください。
ファイルは暗号化されていません。共有PCではWindowsアカウントのアクセス管理にも注意してください。

## 更新・終了

トレイメニューから終了してから、新しいZIPを別フォルダーへ展開して起動します。
実行中のフォルダーへの上書きは避けてください。設定と履歴はアプリフォルダーとは別に保存されます。
削除する場合はアプリを終了し、展開フォルダーを削除します。保存データも消す場合は上記AppDataフォルダーを別途削除します。

録音ショートカットは設定の「操作」で変更できます。左右Ctrl・Altの単独押し、Alt＋カンマなどの組み合わせに対応します。単独キーは離した時に動作し、他のキーやマウス操作と併用した場合は開始しません。既存のショートカット設定は更新後も保持します。設定ウィンドウにフォーカスがある間は録音ショートカットを抑止します。


## 設定画面

「操作」「辞書」「履歴」「ファイル読込」「その他設定」「アプリ情報」に分かれています。
辞書内では「用語辞書」と「表記の置換」を左右のタブで切り替えます。
音声・動画は「ファイル読込」、アクセントカラーは「その他設定」から設定します。
録音ウィンドウは幅168 DIPが初期値で、140〜420 DIPに変更できます。保存済みのサイズは保持します。

「操作」のノイズ閾値は、認識に送るマイク音声の最低音量です。左端の−80 dBはオフ。閾値を上げると小さな音を無音として送ります。語尾を切りにくくするため、閾値を下回った直後の約200msは残します。ファイル読込には適用しません。

## ローカルMCP接続

初期状態で `http://127.0.0.1:55888/mcp` のStreamable HTTP接続が有効です。Gourdyの起動中だけ接続できます。stdio方式は提供しません。
「MCP接続」タブで無効化・ポート変更ができます。ファイル専用で、マイク録音やリアルタイム入力の操作は公開しません。
接続先をトグルで選び「MCP設定を追記」を押すと、次のユーザー共通設定に `gourdy` を追加します。

| 接続先 | Windowsの標準保存先 | 設定形式 |
| --- | --- | --- |
| Claude Code | `%USERPROFILE%/.claude.json` | `mcpServers.gourdy`、HTTP |
| Codex | `%USERPROFILE%/.codex/config.toml`（`CODEX_HOME` 指定時はそちら） | `mcp_servers.gourdy`、`http_headers` |
| VS Code（標準プロファイル） | `%APPDATA%/Code/User/mcp.json` | `servers.gourdy`、HTTP |
| Cursor | `%USERPROFILE%/.cursor/mcp.json` | `mcpServers.gourdy`、URLとheaders |

ClaudeはClaude Code向けです。Claude Desktop、VS Codeの名前付きプロファイル・Portable版・Insiders版、各アプリの独自ユーザーデータディレクトリはこの自動追記の対象外です。
既存の設定・コメントを保持し、変更前のファイルを同じフォルダーへ `.gourdy-<識別子>.bak` として保存します。同一設定は追加せず、同名の異なる設定や構文エラーは対象ごとに表示します。ポートなどを変更した場合は接続先の `gourdy` 項目を確認・削除してから再度追記してください。
設定とバックアップには認証トークンが含まれます。公開・共有しないでください。Gourdyを起動したまま、接続先アプリを再起動し、必要なツール承認を行ってください。「接続設定をコピー」はClaude Code・Cursor用の手動設定にも使えます。

設定仕様の確認元：[Claude Code](https://code.claude.com/docs/en/mcp)、[Codex](https://developers.openai.com/codex/mcp)、[VS Code](https://code.visualstudio.com/docs/agent-customization/mcp-servers)、[Cursor](https://prod.cursor.com/help/customization/mcp)。

利用できるツール:

- `prepare_file`：ローカル音声・動画の絶対パスを検査してジョブIDを返します。
- `start_transcription`：IDを指定して開始・再開します。処理完了を待たずに応答します。
- `get_transcription`：進捗、区間のエラー、途中結果・全文を取得します。
- `list_transcriptions`：保存したジョブを一覧表示します。
- `cancel_transcription`：指定した実行中ジョブを中断します。保存済み区間は残ります。

一度に処理するジョブは1件です。録音中などは開始できず、理由を返します。MCP経由の結果も「ファイル読込」から確認できます。ローカル接続でも認証が必要で、外部からの接続や不正なOrigin/Hostは受け付けません。ポート使用中などで起動できない場合は設定画面に原因を表示し、別のポートへ黙って切り替えることはありません。

## 吹き出しと録音画面

通常時は録音画面の左下に文字を表示しません。マイクにマウスを乗せると、操作と設定中のショートカットを看板で表示します。エラーや入力停止などのお知らせがあると、左下に本体とつながる「i」ボタンが現れます。クリックすると、文字起こし結果とは別のお知らせ用吹き出しを開きます。×で吹き出しだけ閉じ、もう一度「i」で開けます。長い本文は縦スクロールします。お知らせの白背景は初期オンで、「その他設定」の「お知らせの背景を表示」で無効化できます。結合した円の本体にはシャドウを付けます。マイクと歯車の丸背景、音量バーは待機中からアクセントカラーを使い、録音中のマイクとバーは濃い色になります。

入力欄が見つからない場合もマイク録音を開始し、吹き出しへ文字起こしします。入力監視そのものの故障などはこの切替の対象ではなく、エラーを表示します。
入力途中にフォーカスが外れた場合も、未入力の続きが吹き出しに表示されます。停止後も残り、吹き出し専用の×か、入力欄にフォーカスした次の録音開始で閉じます。
吹き出し上部のコピー・入力ボタンは録音と補正の終了後に使えます。入力する場合は、入力先にカーソルを置いてから押してください。

改行はそのまま表示し、長文は本文だけ縦スクロールします。上部の操作ボタンは固定です。末尾を見ている間は自動追従し、過去の行を見返している間は位置を維持します。


## AI接続（0.7.6・試験機能）

設定の「AI接続」でAPIキーを保存し、共通の「使用するAI」を選びます。保存だけではクラウドへ切り替わりません。
- ローカル：設定画面でモデルを取得して選択します。マイクの音声を外部APIへ送りません。
- OpenAI Realtime + Luna：gpt-live-transcribeで途中から認識し、gpt-5.6-lunaで補正・音声コマンドを判断します。
- Gemini：gemini-3.5-transcribe-liveで途中から認識し、gemini-3.5-flashで補正・音声コマンドを判断します。

クラウド利用料はAPI提供元へ別途支払います。ChatGPTやGeminiの定額プランとは別です。キーの保存は接続確認ではありません。実サービスの通し試験は未実施です。
マイク・ファイル読込・保存録音の再認識・MCPは共通のAI接続を使います。用途別の設定はありません。BYOKではローカルモデルの取得は不要です。ファイルは区間ごとに実時間相当でAPIへ送り、失敗時は最大3回試行します。再送にも料金がかかる場合があります。
通信に失敗した場合は理由を表示し、認識済みの原文を残します。別プロバイダーへの自動切替や自動再送は行いません。

## 録音画面の表示切替（0.7.6）

録音ショートカットを400ms以内に2回押すと、常時表示とトレイ格納を切り替えます。格納中の1回押しは表示と録音開始、次の1回押しは停止です。停止後に吹き出し・お知らせがあれば表示を保ち、×で閉じると格納します。
本体の出現・格納は泡のモーションで表示します。Windowsのモーション軽減設定では即時切替に近い動作になります。


### 上位補正とコマンドモデル

「補正に上位モデルを使う」はローカル専用です。操作タブのダウンロードボタンからQwen3-4B Q4_K_M（約2.5GB）を取得すると有効になります。取得済みではボタンを隠し、スイッチで切り替えます。音声コマンドと同じモデルを共用します。
BYOKではこの切替を使わず、OpenAIはgpt-5.6-luna、Geminiはgemini-3.5-flashで補正とコマンド操作を行います。

押して話すコマンドの初期キーは右Altです。押している間に話し、離すと操作を判断します。既に保存してあるショートカットは保持するため、変更する場合は操作タブのコマンド欄で右Altを登録してください。

### 吹き出しと除外リスト

吹き出しの文字を選択してコピー・入力を押すと、選択部分だけが対象になります。選択していなければ表示中の全文が対象です。入力先へ送れた範囲が不明な場合も、録音・補正の完了後に手動入力できます。既存の文章との重複は入力前に確認してください。通常の手動入力はクリップボード経由です。
ダブルタップでの格納は、吹き出し・お知らせが残っていても実行します。内容は保持し、再表示時に戻します。録音終了後の自動格納は、引き続き追加表示を閉じてから行います。
辞書タブの「自動取り込みの除外リスト」で、削除した取り込み語を確認し、個別に除外を解除できます。解除後は次回の自動取り込みで再登録されます。手動の辞書登録・取り込みは除外中でも可能です。古い取り込み記録の表記はWindows辞書に残っていれば復元し、分からないものも表記不明として解除できます。
