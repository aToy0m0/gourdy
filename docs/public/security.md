# セキュリティとデータの扱い

**開発中のため、セキュリティ対策・監査は万全ではありません。**
第三者による包括的な監査、すべての依存の脆弱性確認、コード署名、あらゆる入力先への安全性保証は完了していません。
機密情報を扱う用途には現時点で推奨しません。

## 処理と通信

ローカル接続を選ぶと、音声認識・日本語解析・LLM補正を端末内で処理します。任意のBYOKを選ぶと、マイクや読み込みファイルの音声・補正対象の文章・前後の文脈・辞書をOpenAIまたはGoogleへ送ります。音声コマンドでは選択中の文字列も送ります。ファイル読込・保存録音の再認識・MCPにも同じ接続先を適用します。
開発セットアップと任意モデル取得は外部配布元に接続します。LLMのローカルサーバーはループバックで使用します。ファイル文字起こし・辞書編集・履歴確認用のMCPも初期状態でループバックの55888番ポートを使い、Bearer認証とHost/Origin検査を行います。MCPは設定から無効化できます。接続設定には認証トークンが含まれるため、公開Issueやログに貼らないでください。
「ローカル完結」は、端末自体の侵害や別アプリによる情報取得まで防ぐ保証ではありません。

## 保存するデータ

設定、辞書、文字起こし履歴、保存録音、会議処理の途中結果をユーザーデータフォルダーに保存します。
保存録音は初期状態で有効です。不要なら設定で無効にし、既存の録音も一覧から削除してください。
APIキーはWindowsのsafeStorage（DPAPI）で暗号化し、ユーザーデータ内のcredentialsフォルダーへ保存します。キーは設定画面へ返さず、平文でログへ記録しません。同じWindowsユーザーの侵害から守る保証はありません。その他の履歴・音声・設定データは暗号化されていません。バックアップや端末共有の扱いも含め、[導入ガイド](getting-started.md)の保存先を確認してください。

## 入力とモデル

自動入力は外部アプリへキー操作を送ります。入力先確認・手動操作の検出があっても、誤判定を完全には排除できません。
認識・補正には誤りがあります。重要な文章は送信前に見直してください。
音声コマンドはオプトインです。ローカルでは追加モデルが必要で、BYOKでは同じ接続先の補正モデルを使います。
不正な音声・動画や改ざんされたモデル・依存を開くリスクも残ります。

## 問題の報告

公開Issueへ音声、認識原文、個人情報、秘密情報を貼らないでください。
機密性の高い脆弱性は、[GitHubの非公開脆弱性報告](https://github.com/aToy0m0/gourdy/security/advisories/new)から連絡してください。公開Issueへ詳細を投稿しないでください。

初回は接続未設定です。モデルの取得は明示操作に限ります。保存キーは設定画面から削除でき、使用中の接続は未設定へ戻ります。インストーラー版のアンインストールでも保存キーを削除しますが、更新時は保持します。提供元でのAPIキー失効は別操作です。

MCPの認証済みクライアントは、辞書・表記置換の確認／追加／削除、通常履歴の本文・原文、保存録音の一覧、ファイル文字起こしの結果にアクセスできます。マイク録音やキー操作は公開しません。接続先クライアントによる取得内容の外部送信は、そのクライアント側の設定に従います。
