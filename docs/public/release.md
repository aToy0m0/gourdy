# 配布とリリース

現行版は **0.5.1**。明示的な判断なしにマイナーバージョンを上げません。
ソースは公開リポジトリ、ビルド済みアプリはGitHub Releasesで配布する構成です。
現在はローカルの配布候補を作成する段階で、公開はしていません。

## 作成

```powershell
npm test
npm run test:nlp
npm run dist -- --config.directories.output=dist-staged
npm run release:zip
```

`release/okosy-0.5.1-windows-x64.zip` と `release/SHA256SUMS.txt` を生成します。
ZIPにアプリ・標準モデル・依存ランタイム・公開ドキュメント・ライセンスを含めます。
利用者は展開して起動できます。追加のコマンドモデルは同梱せず、利用者が有効化したときに取得します。
パッケージ作成成功は、法的条件・セキュリティの監査完了を意味しません。

## 公開前の残作業

- [第三者表示](THIRD-PARTY-NOTICES.md)の未完了項目を解消。特にFFmpegの対応ソース・ビルド手順・依存ソースの同時提供。
- Moonshine native内部、MPL対象、辞書派生データの通知と対応ソースの網羅確認。
- クリーンなWindows環境で導入・録音・リアルタイム入力・会議読み込みを確認。
- 公開リポジトリの非公開脆弱性報告窓口を設定。
- 最新の依存脆弱性確認、署名の扱い、ZIPとハッシュの最終照合。
- Git追跡対象に認証情報・個人データ・内部メモがないことを再確認。

これらが完了するまでは配布候補を一般公開しません。特に対応ソースは上流へのリンクだけで完了扱いにしません。

## 公開操作

公開先を決めた後、レビューしたコミットをpushし、`v0.5.1` のリリースにWindows ZIP、SHA256、必要な第三者対応ソースを添付します。
GitHubが提供するアプリ本体のSource code ZIPだけでは、同梱する第三者バイナリの対応ソースを満たしません。
READMEの「公開準備中」を配布実態に合わせて更新します。公開操作とタグ作成は、ローカルビルドから自動実行しません。

## 公開範囲

`docs/public/` だけを公開ドキュメントとして追跡・同梱します。
ローカルの調査・作業メモ、録音、artifacts、モデル、ランタイム、生成物はGit管理から除外します。
アプリのソースマップは生成・同梱しません。第三者ランタイムの必要なライセンスファイルは維持します。
